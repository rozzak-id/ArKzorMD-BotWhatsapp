# DTCG Token Reference

The Design Tokens Community Group (DTCG) standard specifies token layers:

## 1. Primitives
- Spacing: 2px (2xs), 4px (xs), 8px (sm), 12px (md), 16px (base), 24px (lg), 32px (xl), 48px (2xl), 64px (3xl).
- Radii: 4px (xs), 6px (sm), 10px (md), 14px (lg), 20px (xl), 9999px (full).
- Palette (Slate): 50 (#f8fafc) to 950 (#020617).
- Palette (Emerald/Cyber): 400 (#34d399), 500 (#10b981), 600 (#059669), 700 (#047857).

## 2. Semantics
- `--bg`: Application background (`#0b0f14` in dark, `#f8fafc` in light).
- `--surface`: Standard container background (`#11161f` in dark, `#ffffff` in light).
- `--surface-2`: Elevated elements, pills, and dropdowns (`#171f2c` in dark, `#f1f5f9` in light).
- `--surface-sunken`: Inputs, code blocks, sunken areas (`#0c1017` in dark, `#eef2f6` in light).
- `--border`: Card and section borders (`#212b3b` in dark, `#e2e8f0` in light).
- `--border-subtle`: Subtle dividers (`rgba(255,255,255,0.06)` / `rgba(0,0,0,0.06)`).
- `--accent`: Emerald cyber brand color (`#10b981` in dark, `#059669` in light).
- `--accent-glow`: `0 0 20px rgba(16, 185, 129, 0.2)`.

## 3. Shadows & Elevation
- `elevation-1`: Subtle resting card shadow with hairline border.
- `elevation-2`: Raised hover state and popovers.
- `elevation-3`: Modal dialogs and active floaters.
